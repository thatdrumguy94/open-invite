# Security Policy

## Reporting Security Issues

We take the security of OpenInvite seriously. If you believe you have discovered a security vulnerability, please do NOT report it through public GitHub issues.

Instead, please report security vulnerabilities responsibly by creating a private security advisory on GitHub or emailing the project maintainer directly.

Please include:
- A description of the issue.
- Steps to reproduce or proof of concept.
- The potential impact of the vulnerability.

We will acknowledge receipt of your report, investigate the issue, and provide a patch promptly.
